## What works

- Organiser signup/signin simulation, group setup and editable date windows.
- Revocable invitation links; name-only guest entry without signup.
- Private brief views, drafts, confirmed input, equal interest stars, editable natural language, sample voice transcript and optional local interpretation.
- Four rule-based sample concepts checked against confirmed availability, whole-trip ceilings and supported requirements.
- Itinerary choices and item-level polls; editable ballots, abstention, closure rules and ties.
- Complete individual cost calculations, room and vehicle sharing, attendee-only optional charges, fees and contingency.
- Versioned ready/change/decline responses. Material changes invalidate old readiness.
- Pending, agreed and postponed outcomes; explicit roster proposals and repricing.
- Provider comparisons in five categories; booking task ownership and versioned self-reported status.
- Safe plan summary copying and shared decision history.
- Browser persistence, reload, failed-save retry demonstration, and responsive layouts.

## Deliberate demo limits

- Data is stored on this browser's origin using localStorage. Session identity and unfinished form fields use sessionStorage.
- Links do **not** synchronise trips across devices, browsers or origins. Real shared trips need Supabase later.
- The persona switcher is a test tool. This is not secure authentication or real access control. Use fictional data.
- Password fields are a visual preview: their values are not saved or verified.
- Voice does not record audio. The interpretation preview uses simple local rules and sends nothing to an AI provider.
- Concepts, times and prices are illustrative. This catalogue covers Goa, Bengaluru-origin travel, three days / two nights, and groups up to six. Other inputs are retained but block complete-price validation where unsupported.
- Food venues and activity options are suggestions, not verified inventory. External buttons open generic provider sites.
- A reported booking is not provider verification or a reservation. Reports from an older plan version remain labelled as earlier reports.
- No Supabase project, live AI, GitHub repository, email service, payment or booking API was modified or connected.

## Run locally

Use Node 22.12+ and pnpm. The supplied .mise.toml retains the reference's Node 22 and pnpm 10 toolchain; local verification used Node 22.14 and pnpm 11.25.

```sh
pnpm install
pnpm run dev
```

The default preview port is 8443. For a different port, set PORT before running the development command. Figma Make manages its own preview server.

```sh
pnpm run typecheck
pnpm test
pnpm run build
```

The format command uses the installed TypeScript printer; this avoids a syntax issue in the supplied reference formatter.

The tests use Node's built-in runner and experimental TypeScript stripping in Node 22. This warning does not affect the passing test results. Browser checks in tests/browser.mjs are optional and require Playwright plus Chrome; they are not runtime dependencies.
