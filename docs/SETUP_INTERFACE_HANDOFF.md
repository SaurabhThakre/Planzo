## Implementation

TripSetup replaces the live sample setup. Tentative duration accepts whole 1–365 days; minimum accepts whole 1–100 travellers including the organiser. The estimate is separate from the exact times of one to three tentative date windows. Future boundaries and a future response deadline are checked in Asia/Kolkata. Collection supports up to 100 members. The current illustrative Goa price reference still covers three days/two nights and at most eight travellers; unsupported trips remain blocked from false costed readiness. Supported one-person plans can publish.

DateTimeField separates the calendar from 24-hour hour/minute selectors. Apply commits; Cancel discards. Setup cannot submit while an editor is open. It also replaces combined datetime inputs for later response deadlines, item-poll deadlines and booking-task due times. Defaults are future dates.

Priority-star controls and live captions are removed, while stored stars and immutable snapshots are retained. Existing hard-requirement fields stay until the later chatbot replacement. The nonfunctional live voice preview is hidden. Every live route has a short instruction. The one History link opens caller-scoped shared decision events, saved versions, shared/own booking reports and milestone changes; these cards no longer repeat in ordinary planning/booking views. Organiser revision tools are collapsed and redundant overview shortcuts removed.

Only genuinely unused collecting organiser-only trips can use Delete draft: no invitation, saved private draft, planning draft/poll or plan version. This is recoverable deletion into Deleted drafts, retaining records. Archive moves used/shared trips into Archived for all members without deleting data. Only the organiser can remove/restore; acknowledgement, expected revisions and request-bound idempotency are required. Restore returns an unplanned trip to collecting, or a trip with a plan/draft to revise for fresh review. It never revives agreement. Archived private input is read-only. No physical row-deletion endpoint exists.
