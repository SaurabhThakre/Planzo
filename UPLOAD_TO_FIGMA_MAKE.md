# Planzo complete-source import and preview

Working destination: [Planzo — Working Prototype](https://www.figma.com/make/4tPr5AkQO1g0L1esRvGRjz).
Original preserved file: [Planzo-make](https://www.figma.com/make/6LHtBsNu1CmMtUlWAdWgi7/Planzo-make).

The user authorized the full editable project: src, public, all local assets and fonts, configuration including hidden .figma, tests, documentation and supporting files. Dependencies and generated output (node_modules and dist) are rebuilt by Figma and are excluded, along with OS metadata.

The connector temporarily packages the source for transport, then expands the files into the Make project. The user confirmed this is acceptable; a ZIP attachment is not the deliverable. The initialized original Make could not accept an import through the connector, so the user selected a new blank Make in GFMB Project.

The four lifecycle scripts are executable regular files. Installation uses the existing lockfile. The foreground Vite server respects the assigned host and port and uses exec. Preview and production hooks build dist and guard its presence before calling Figma's deployment CLI. These scripts do not authorize publishing.

Keep the agreed scope: browser-saved interactive demo, simulated identity and AI, fictional prices. Do not connect Supabase or live AI in this step. See the latest handoff and import receipt for the actual source-import and preview status.

## Preview checks after upload

- Welcome illustration, icons and Inter fonts load without broken assets.
- Explore the Goa sample; select a demo persona and open their own preferences.
- Change and save an input, reload, and verify that it remains.
- Confirm that an unaffordable plan or unknown critical price blocks readiness.
- Open an itinerary item poll, save ballots and close it under the stated rule.
- Verify that five ready responses cannot close the trip.
- Change a material term; old responses become historical and a new version needs fresh confirmation.
- Check the full estimate appears above readiness controls on a phone.
- Close an agreed round; inspect provider categories and report an assigned task.
- Verify provider navigation leaves a pending task pending.
- Open an invite in another tab of the same browser and join without signup.

Local data is tied to the preview's origin. Figma's editing preview and deployed site can have different origins and therefore separate demo data. Neither will synchronise with another person's browser until a backend is connected.
